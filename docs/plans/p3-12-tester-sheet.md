# Ski Area Design Challenge: tester sheet (v0.3.0)

Thanks for trying the game. This is an early test build. We want to see how far you get on your own, so this page
says **what** to try, not how. If you get stuck, write down where and why, then carry on or stop. Nobody will help
during the session; being stuck is a useful result.

## Before you start
- You need Windows 10 or 11 and the file `SkiAreaDesignChallenge-0.3.0-win64.zip` (about 360 MB). Download it from
  the [release page](https://github.com/ljs294/ski-area-design-challenge/releases/latest): under **Assets**, click
  the `.zip` file.
- **Before unzipping:** right-click the zip › Properties › tick **Unblock** › OK. The build isn't signed yet, and
  without this Windows may refuse to start it.
- Unzip it anywhere you like (not inside Program Files). `README.txt` inside the zip explains how to run it.
- If Windows says "Windows protected your PC" when you start it, click **More info**, then **Run anyway**.
- **Turn the internet off** (Wi-Fi off or cable out) for the first launch.
- Keep a notepad or your phone handy for notes.

## What to try
1. With the internet off, start the game and get to a mountain you can look around.
2. Turn the internet back on. Find a mountain or ski area you like anywhere in the United States, and get it into the
   game.
3. Explore it: look around, change things, see what the game shows you.
4. Take a picture of the mountain that you'd be proud to share.
5. Build a small ski area on it: at least one lift and a couple of trails.
6. Save it, quit the game, start it again and get your ski area back.

There's no time limit. Thirty minutes to an hour is plenty.

## Notes to keep
For each thing that surprised, confused or annoyed you, note:
- what you were trying to do;
- what happened;
- what you expected to happen.

Also note anything you liked.

## Sending it back
Use **Send feedback** in the game's menu (top right). Pick Problem or Suggestion, paste or type your notes, and keep
the screenshot, logs and save ticked. **Save and open GitHub** saves one zip file, shows it in a folder and opens a
GitHub issue: drag the zip into the issue and submit it. You can send several, one per problem.

- Filing the issue needs a free GitHub account. Without one, send the zip (it's in
  `%LOCALAPPDATA%\SkiAreaDesignChallenge\Reports`) and your notes to whoever gave you the game.
- Your pictures are in `Pictures\Ski Area Design Challenge`; add the ones you like.
- GitHub issues are public. The report holds the game's version, your computer's details (Windows, processor,
  graphics card, screen and settings), the game's logs with your Windows user name taken out, and your save. Untick
  anything you'd rather not send.

**If the game won't start at all**, send these instead (paste each path into File Explorer's address bar):
- `%LOCALAPPDATA%\SkiAreaDesignChallenge\Logs`;
- `Player.log` from `%USERPROFILE%\AppData\LocalLow\Alpine Labs\Ski Area Design Challenge`;
- your Windows version and graphics card (Settings › System › About, or Task Manager › Performance › GPU).
