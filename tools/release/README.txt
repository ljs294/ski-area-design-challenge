Ski Area Design Challenge {VERSION}
by Alpine Labs

A ski resort designer on real mountains, built from U.S. Geological Survey lidar.


RUNNING THE GAME

1. Before unzipping, right-click the zip file, choose Properties, tick "Unblock" at the bottom and click OK.
   This test build isn't signed, and without this step Windows may refuse to start it.
2. Unzip this folder anywhere you like (not inside Program Files), for example your Desktop.
3. Double-click SkiAreaDesignChallenge.exe.

If Windows still says "Windows protected your PC", click "More info", then "Run anyway".

The game opens on the title over Jackson Hole, which is built in and works offline. New Area downloads another
mountain, which needs an internet connection; downloads go to %LOCALAPPDATA%\SkiAreaDesignChallenge.

To uninstall, delete this folder. Your downloaded areas and the error logs stay in
%LOCALAPPDATA%\SkiAreaDesignChallenge until you delete that folder too.


WHAT YOU NEED

- Windows 10 or 11, 64-bit, with a DirectX 11 or 12 graphics card
- About {SIZE} of disk space for the game, plus about 200 MB for each area you download
- Tested on Windows 11 with a GeForce RTX 3060 Ti. The minimum hardware hasn't been measured yet; if the game runs
  slowly, lower Settings > Graphics > Quality preset.


REPORTING A PROBLEM

When something goes wrong, the game saves an error log and shows "A log was saved" with an Open folder button.
The logs are in:

    %LOCALAPPDATA%\SkiAreaDesignChallenge\Logs

Each file starts with the game's version and your computer's details (Windows version, processor, graphics card,
screen and settings), followed by the errors. It holds nothing else about you.

To send one, either:
- in the game, open Settings > Data > Logs and click Copy report, then paste it into your message; or
- attach the newest errors-....log file from the folder above.

If the game closes by itself without saving a log, please also send these two files:
    %USERPROFILE%\AppData\LocalLow\Alpine Labs\Ski Area Design Challenge\Player.log
    %USERPROFILE%\AppData\LocalLow\Alpine Labs\Ski Area Design Challenge\Player-prev.log

Please say what you were doing when it happened, and the version: {VERSION}. The version is also shown at the bottom
left of the title and in Credits.

NOTICES.txt lists the fonts, data and software the game uses, and their licences.
